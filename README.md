# Slop Taipei

A Taipei City simulation built with [three.js](https://threejs.org/), WebGPURenderer, and TSL. Explore Manhattan on foot, by car, by bicycle, or by helicopter.

Forked from https://github.com/mrdoob/slop-newyork

[Try it live](https://hebe13579.github.io/slop-taipei/?city=taipei) 

## Make it your own

Fork it, remix it, improve it, break it. Make games, animations, films, experiments, or something completely different. Use it as a starting point and take it wherever you want. Have fun!
