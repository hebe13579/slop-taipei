# Slop Taipei

Forked from https://github.com/mrdoob/slop-newyork

A Taipei City simulation built with [three.js](https://threejs.org/), WebGPURenderer, and TSL. Using Muse.ai 

Cover most of Taipei basin (Beitou, Taipei Station, Xinyi, Songshan)

Including elevated highway, bridges, iconic buildings, airport. Road and most building are procedural generated. For best experience please try with helicopter! 

[Try it! slop-taipei](https://hebe13579.github.io/slop-taipei/?city=taipei)
