# Release notes — Wed 2026-10-28

What went live on https://hebe13579.github.io/slop-taipei/?city=taipei today. One line per change, in the order it merged. PR numbers link to the code; issue numbers link to the request.

- **Guandu green flicker fixed** — park green patches no longer flash as the camera moves. (PR #224, issue #206)
- **Highway ramp connections fixed** — ramps now join decks at the right heights instead of floating or burying. (PR #225, issue #211)
- **Creek widths corrected** — 貴子坑溪 narrowed to its real ~12 m channel instead of a wide river. (PR #226, issue #223)
- **Cloverleaf interiors cleared** — no more buildings inside highway loop ramps. (PR #227, issue #213)
- **Building heights sanity-checked** — one tall permit no longer donates its height to every small lot around it. (PR #228, issue #219)
- **You can drive on elevated decks, buildings are solid** — decks are drivable and buildings block the car instead of letting it pass through. (PR #229, issue #207)
- **School campuses built** — schools now read as campuses: track, classroom blocks, fence, gate, trees. (PR #230, issue #221)
- **Traffic experiment added (off by default)** — cars can drive the road network behind the `?traffic=1` flag. (PR #232, issue #210)
- **Settings gear added** — top-right gear with building density (Coarse / Fine / Dense), graphics quality, and a traffic row. (PR #233, issue #218)
- **Rooftop tin huts got detail** — varied roof shapes, patched panels, and annexes on 鐵皮屋. (PR #234, issue #208)
- **Park dressing added** — benches, lamps, bins, vending machines, restrooms, sculptures, fountains, and bushes in parks; more tree shapes. (PR #236, issue #222)
- **Wenhu line portal trench at Dazhi** — the line now dives underground through a proper cut instead of floating doors. (PR #237, issue #209)
- **Xinyi skybridges built** — the 信義空橋 walkway network, 15 chains, with supports that clear the roads. (PR #238, issue #212)
- **Fences no longer block road mouths** — at every merge/branch, the branching road's fence no longer walls off the start of the road (the bug reported with the Zhoumei Expressway photo). (PR #242, issue #239)
- **Far buildings fade, landmarks stay sharp** — distant buildings fade to faint simple boxes with distance but never disappear; Taipei 101 and other landmarks keep full detail, so 101 still reads from Beitou. New gear row "Distant buildings". (PR #243, issue #240)
- **Schools and landmarks simplified at distance** — fewer objects to draw far away; school trees swap to simple canopies past 700 m. (PR #248, issue #244)

User reports handled today: traffic explained as flag-only (gear switch built the next day); double yellow center lines confirmed missing and filed; school performance report investigated (resolved Oct 29 — running well, kept).
